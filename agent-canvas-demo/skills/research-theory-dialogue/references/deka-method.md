# Dual-Excitation Kinetic Coupling: initial project method

Use this only when the project actually concerns a dual-wavelength plasmonic metal/semiconductor system.

- State H0: apparent dual-light gain is explained by single-light nonlinearity, photon flux, heating, sequence effects, or analysis artifacts.
- State H1: the interaction remains positive after those controls and replicates across independent preparations.
- First scan a fixed-total-power intensity-ratio matrix; retain time-resolved raw data and randomized run order.
- Before mechanism claims, check matched absorbed flux, matched temperature, single-light nonlinearity, illumination order, and material stability.
- Escalate to mechanistic spectroscopy only after reproducible interaction evidence; treat it as discriminating evidence, not decoration.
- Stop the synergy claim if the interaction confidence interval crosses zero, the effect disappears after physical controls, or independent batches disagree.
