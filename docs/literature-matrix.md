# 文献矩阵

在 Scholarium 的「文献订阅 → Vault 文献库」打开「智能文献矩阵」。首次安装后，请在 Obsidian 的第三方插件设置中关闭再打开 Scholarium，或重启 Obsidian。

- 默认按入库时间倒序排列。顶部可改为标题、作者、发表年份、期刊或更新时间，也可点击表头排序。
- 点击标题：有解析正文时打开以「年份-标题」命名的阅读笔记，否则打开原始 PDF 或文献笔记。
- 同一行的总结内容区随行高自动铺满，不再单独设置预览高度；长内容可在对应单元格内滚动阅读。
- 「PDF」「解析全文」「文献笔记」分别打开对应文件。
- 标签按类别统一着色：`topic` 橙色、`journal` 蓝色、`source` 紫色、`year` 绿色，其他类别灰色。圆角色块只显示 `/` 后的内容，悬停可查看完整标签；笔记中的原始标签保持不变。
- 点击标签栏的「＋」，选择类别并填写内容即可添加标签；也可选择已有类别或输入自定义类别。保存时自动去重，内容中的空格转换为连字符。标签写入对应文献笔记的 `tags` 属性；只有 PDF 的文献会创建关联的标签笔记，刷新后仍会保留。
- 没有总结的文献可点击「手动填写总结笔记」，创建并打开空白模板；已有总结时点击「总结笔记」打开原笔记。按章节手动填写并保存，无需调用 AI。
- 点击单篇文献的「AI 总结论文」启动总结，只在该文献的操作栏查看进度，也可取消该篇总结。页面顶部和底部不显示任务栏。已有总结时再次点击会生成一份新的总结笔记。
- 可以连续点击多篇文献或批量选择文献进行总结：最多同时运行 3 篇，其余自动排队。每篇操作栏中的进度条从左向右显示阶段进度，文字显示等待、检查本地全文、下载或解析、AI 总结、保存等阶段。成功后自动收起进度，不显示完成提示；失败原因默认折叠，并可关闭，成功重试后旧错误会消失。阶段进度不代表下载字节或 AI 生成量的精确百分比。
- 总结优先读取本地已抓取的正文。原文归档状态为 `pending` 时，只要保存的内容具备正文结构，也可直接用于总结；仅有摘要或验证页时仍需获取全文。
- 保存后点击「刷新文献与总结」，将手写内容更新到矩阵中。
- 搜索会匹配标题、作者、期刊、DOI、标签和七列总结内容。表格可以横向滚动，每页 50 篇。

## 总结笔记格式

支持 Markdown 同名章节（多行正文）或 `字段:: 内容`。七个字段如下：

```markdown
## 领域基础知识

## 研究背景

## 作者的问题意识

## 研究意义

## 研究结论

## 未来研究方向提及

## 未来研究方向思考
```

总结模板保存在 `literature/summary-notes/`。可在笔记属性中修改 `title`、`year`、`authors`、`journal` 和 `reading_status`（未读/在读/已读）；`fulltext_path` 用于关联原文。已有笔记放在 literature 下，并填写相同 DOI 或原文路径，也可与文献关联。文献笔记的 `summary_path` 属性还可指向 Vault 其他位置的总结笔记。

发表年份与入库时间分别读取；未找到发表年份时显示「年份待补」。PDF 内容相同的副本按文档身份合并展示。新解析目录使用年份和标题，加身份后缀避免重名覆盖。

命名阅读入口保存在 `Scholarium/Literature Reading/`。已存在的解析正文、图片、溯源和校验文件保留，阅读入口嵌入解析正文。

实现参考：[Zotero Lit AI Matrix](https://github.com/Tenor-John/Zotero-Lit_Ai_Matrix)。本次整合七个总结字段、矩阵阅读入口、搜索和排序；未移植 Zotero 使用热力图。
